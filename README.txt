PREVIEW LOCALLY ON MAC
1. Unzip the archive.
2. Open the Nivas_Kannan_Portfolio folder.
3. Double-click index.html to preview it in your browser.

DEPLOY TO THE EXISTING VERCEL PROJECT (NO GIT CONNECTED)
1. Install Node.js if it is not already installed: https://nodejs.org/
2. Open Terminal and install Vercel CLI:
   npm install -g vercel
3. In Terminal, change directory into this folder (the folder containing index.html).
4. Run:
   vercel link
   Select the existing project named nivas-kannan-portfolio when prompted.
5. Deploy a preview first:
   vercel
6. If the preview looks correct, deploy to production:
   vercel --prod

IMPORTANT
- Do not create a new Vercel project during `vercel link`.
- Check the preview deployment before running `vercel --prod`.
- The production deploy updates the existing project only if it is linked to the correct Vercel project.
